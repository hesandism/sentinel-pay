# Community Cloud prefers the requirements.txt next to the entrypoint over the
# repo-root one, so this slim set is what the PUBLIC DEMO builds from. It skips
# the whole ML/Postgres stack — the demo (DEMO_MODE=1) fabricates its data in
# demo_data.py and never opens a database or network connection.

# NOTE: versions here MUST have prebuilt wheels for the Python the host picks.
# Community Cloud defaults to a very new Python (3.14), which has no wheels for
# old numpy/pandas/Pillow — those then try to COMPILE from C source and fail
# (the "could not find zlib for Pillow" error). These floors resolve to wheels
# on 3.11–3.14 alike, so nothing is ever built from source.
